# Built-in guide models

Seven models, each as `.glb` (Max's dashboard, three.js) and `.usdz` (Salman's phone, RealityKit), built from one
source of geometry by `build_models.py`, so the two formats can't drift apart. Names match `ModelName` in
`contracts/protocol.ts`; the tests fail if they don't.

| Model | Height | What it is | Triangles | glb · usdz |
|---|---|---|---|---|
| `screw` | 1.6 cm | pointed shaft, round head | 78 | 3.5 · 4.1 KB |
| `bolt` | 3.0 cm | flat-ended shaft, hex head | 54 | 2.9 · 3.5 KB |
| `arrow` | 5.0 cm | cone point down, shaft up | 54 | 2.9 · 3.5 KB |
| `screwdriver` | 18 cm | tip, shaft, handle | 112 | 4.4 · 4.7 KB |
| `hand` | 18 cm | pointing hand, index fingertip down | 144 | 6.2 · 6.4 KB |
| `cable-plug` | 7 cm | RJ45 plug and a short cable | 102 | 4.6 · 5.0 KB |
| `ssd` | 8 cm | M.2 2280 SSD, contact edge (with its notch) down, chips on +Z | 72 | 4.8 · 5.3 KB |

## Conventions (decided by Laura, 2026-11-14)
- **Metres, +Y up.** Both apps' defaults, so nothing is rotated or scaled on load.
- **The working tip is at the origin** (screw point, arrow point, fingertip, plug contacts, SSD contact edge), so the tip lands exactly
  where the expert places the object.
- **Each model rises along +Y from its tip**, so +Y means "away from the part": `pull` moves along +Y, `push` along
  -Y, `unscrew` spins around Y. Rotate the object in the guide to point it elsewhere; the SSD lies flat in a laptop, so it needs a 90° turn to sit in its bay.
- One flat orange material, no textures, low poly, 16-bit indices: each file is under 7 KB.

## Rebuild after a change
```bash
python -m venv .venv && .venv/Scripts/pip install -r assets/models/requirements.txt   # macOS/Linux: .venv/bin/pip
.venv/Scripts/python assets/models/build_models.py
.venv/Scripts/python -m unittest discover assets/models
```
`usd-core` (Pixar's USD library) is only needed to rebuild; neither app depends on it. The build fails if a `.usdz`
breaks USD's package, geometry or material checks. Changing a model's name, size or origin breaks both apps' layouts:
flag it to @max and @salman on the board.
