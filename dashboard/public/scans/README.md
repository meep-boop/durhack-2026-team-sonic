# Scans of the demo set

Scaniverse exports of Ahmed's laptop on its board, kept in git so every teammate's dashboard loads the same files
(Max, 2026-11-15). Open one with `?closed=<file>&open=<file>` (or `?splat=<file>`). A file's name is its id for
calibration, so a rescan gets a new name: never overwrite a file here.

| File | Kind | State | Marker in view | Usable |
|---|---|---|---|---|
| `open-mesh-0217.usdz` | textured mesh, 186,092 triangles, 6.6 MB | cover off | **no** | reference only: can't be calibrated |

The rescans of both states, with the marker in view, are still to come.
